## Release process

A versioned release should include:

1. an owner-approved semantic version;
2. a green default-branch pipeline;
3. a reviewed changelog section moved out of **Unreleased**;
4. an annotated Git tag;
5. a GitLab Release containing installation and compatibility notes;
6. the explicit software license selected in the licensing issue.
